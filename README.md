# Balance

An original, single-player-first 2D real-time strategy game built with
Godot 4.7.2 and GDScript.

**Status:** P001 — tactical movement sandbox, with a first visual pass. Four
Blue units can be selected and ordered around a small woodland map with a
central Orichalcum formation; four Red units stand still and block movement.
There is no combat yet. See [docs/ROADMAP.md](docs/ROADMAP.md).

All art is original and generated by scripts in this repository: ground
textures with Python and Pillow, and units, trees, rocks and crystals as
low-poly models rendered to sprites in Blender.

## Controls

| Input | Action |
| --- | --- |
| Left click | Select one Blue unit (click empty ground to clear) |
| Left drag | Box-select Blue units |
| Shift + click / drag | Add to the selection (Shift-click a selected unit to remove it) |
| Right click | Move the selected units; each gets its own cell at or near the target |
| S | Stop the selected units |
| Esc | Clear the selection |
| W A S D / arrow keys | Pan the camera (S pans only when nothing is selected) |
| Mouse at window edge | Pan the camera |
| Mouse wheel | Zoom towards the cursor |

A red cross and a short message appear if the target is impassable, outside
the map or has no route (try the walled-off clearing south of the deposit).

## Requirements (Windows)

- Windows 10/11
- [Godot 4.7.2 stable](https://godotengine.org/download/archive/) — the standard
  build, not the .NET build
- Git

The project expects Godot at:

```
C:\Godot\Godot_v4.7.2-stable_win64.exe           (editor / game window)
C:\Godot\Godot_v4.7.2-stable_win64_console.exe   (same, with console output)
```

If yours is elsewhere, substitute your path in the commands below, or set the
`GODOT` environment variable to the console executable for `tools\check.ps1`.

## Setup

```powershell
git clone https://github.com/spyrostrimis/balance3.git D:\Games\Balance3
cd D:\Games\Balance3
& 'C:\Godot\Godot_v4.7.2-stable_win64_console.exe' --headless --path . --import
```

The import step builds the local `.godot/` cache. It is needed once after
cloning and is safe to repeat.

## Run the game

```powershell
& 'C:\Godot\Godot_v4.7.2-stable_win64.exe' --path D:\Games\Balance3
```

## Open in the editor

```powershell
& 'C:\Godot\Godot_v4.7.2-stable_win64.exe' --editor --path D:\Games\Balance3
```

Or start Godot, choose **Import**, and select `D:\Games\Balance3\project.godot`.
Press **F5** to run.

## Run the checks

```powershell
powershell -ExecutionPolicy Bypass -File tools\check.ps1
```

This runs three headless steps and exits non-zero if any fails or prints an
error:

| Step | Command |
| --- | --- |
| Import | `godot --headless --path . --import` |
| Tests | `godot --headless --path . res://tests/test_runner.tscn` |
| Startup | `godot --headless --path . --quit-after 120` |

Tests live in `tests/test_*.gd`; see [AGENTS.md](AGENTS.md) for how to add one.

## Capture screenshots

```powershell
& 'C:\Godot\Godot_v4.7.2-stable_win64_console.exe' --path . --script res://tools/capture_demo.gd
```

Plays a short scripted demo in a real window (select, move, blocked order,
zoom out) and saves PNGs to `screenshots/`, which Git ignores. Add
`--resolution 1920x1080` to test another window size.

## Rebuild the art

Only needed after changing a script in `tools/art/`. Requires Blender 5.2
(default `C:\Blender\blender.exe`, or set `BLENDER`) and Python 3 with Pillow.

```powershell
powershell -ExecutionPolicy Bypass -File tools\build_art.ps1
```

It regenerates `assets/terrain/` and `assets/sprites/` in about a minute.
Run the checks afterwards so Godot re-imports the images.

## Layout

| Path | Contents |
| --- | --- |
| `project.godot` | Godot project settings (repository root is the project root) |
| `scenes/` | Scene files (`.tscn`); `main.tscn` is the startup scene |
| `scripts/sim/` | Game rules with no scene dependencies: map, pathfinding, units, orders |
| `scripts/input/` | Selection rules |
| `scripts/view/` | Ground shader, sprites, scenery, camera, overlay, scale settings |
| `scripts/main.gd` | Connects the simulation, input and scene |
| `data/` | Maps, terrain types and unit types as JSON |
| `assets/` | Generated ground textures and sprite sheets |
| `tests/` | Headless test runner and test scripts |
| `tools/` | Developer scripts; `tools/art/` holds the art generators |
| `docs/` | Design documents, decisions, roadmap, technical baseline |
| `PROMPTS/` | Assignment prompts given to the coding agents |
